## 10. Project Overview

- `artifacts/`: Core application services

  - `artifacts/university-app`: React 19 / Vite single-page frontend application
  - `artifacts/video` & `video-production`: Promotional and demonstration video media assets
- `lib/`: Shared monorepo packages
  - `lib/api-spec`: OpenAPI 3.0 specification schemas
  - `lib/api-zod`: Auto-generated Zod validation contracts
  - `lib/api-client-react`: Auto-generated React Query API hooks
- `docs/`: Comprehensive project documentation (`ARCHITECTURE.md`, `API.md`, `DATABASE.md`, `SECURITY.md`, `UI-UX-IMPROVEMENT-LOG.md`)
- `scripts/`: Operational tools, test runners, database seeds, and verification utilities
- `graphify-out/`: Codebase AST knowledge graph and relationship indexes

### Technologies Used
- **Runtime & Package Manager**: Node.js 24.x, `pnpm@10.34.4` (monorepo workspace)
- **Backend**: Express, TypeScript, Prisma ORM, PostgreSQL, Redis, JWT with 2FA, Helmet, Rate Limiter
- **Frontend**: React 19, TypeScript, Vite 7, TailwindCSS v4, TanStack React Query v5, Wouter, Radix UI, Lucide React, Framer Motion
- **Testing**: Node test runner (`node --test`), Playwright Core / Chromium / Edge for E2E / A11y, Axe-core, custom contract drift checks

### Build, Test, and Execution Commands
- Build: `pnpm run build`
- Type Check: `pnpm run typecheck`
- Lint: `pnpm run lint` (or auto-fix: `pnpm run lint:fix`)
- Test All: `pnpm run test`
- API Tests: `pnpm run test:api` (unit: `--unit`, integration: `--integration`)
- Web Tests: `pnpm run test:web`
- Contract Drift Check: `pnpm run test:contract`
- Full Release Verification: `pnpm run verify`

### Core Code Rules
- All API contracts flow unidirectionally from `lib/api-spec` to `lib/api-zod` and `lib/api-client-react`.
- No direct schema mutation without updating baseline contracts (`SHAHEEN-BASELINE-AND-IMPLEMENTATION-CONTRACT.md`).
- Strict TypeScript: no unvetted `any` casts or blind `@ts-ignore`.

1. **Observe lean-ctx shadow mode**: Standard file read and search tools are auto-routed through `lean-ctx`. When researching code, prefer `ctx_compose`, `ctx_search`, or query tools to prevent context window bloat.
2. **Follow Graphify constraints**: Check `graphify-out/` for dependency structures, but always confirm method calls and line numbers directly in source files using `rg -n`. Always end analysis reports with an explicit `"Could not verify"` section.
3. **Adhere to output constraints**: Keep explanations concise (1 sentence max before action), prioritize bullet points, and eliminate conversational filler.
4. **Preserve Pnpm workspace scoping**: Execute builds and test scripts using the `--filter` flags (e.g. `pnpm --filter @workspace/university-app ...`) to respect package boundaries.
5. **Protect system integrity**: Never run destructive database or cloud commands without interactive confirmation, and keep all operations bounded inside the project root.
